# Architecture: Model Context Protocol (MCP) Server

L'evoluzione moderna di `penguins-eggs` abbraccia l'intelligenza artificiale non solo come strumento di supporto alla scrittura del codice, ma come entità integrata direttamente nel ciclo di vita del sistema operativo attraverso il **Model Context Protocol (MCP)**.

Implementato nativamente in Go (`eggsmcp`), il server MCP permette agli assistenti IA compatibili (come Claude, Cursor, Zed, Roo-Cline o Antigravity) di interagire in modo sicuro, strutturato e contestuale con le funzioni del motore.

---

## 1. Obiettivi e Funzione del Server MCP

Il protocollo MCP colma il divario tra l'ambiente di sviluppo dell'agente IA e il sistema operativo sottostante, consentendo di:
* **Scoperta dinamica dei comandi:** L'agente IA può interrogare direttamente le capacità di `eggs`, scoprendo quali strumenti (`tools`) e risorse (`resources`) sono disponibili sulla macchina ospite.
* **Ispezione in tempo reale:** Permette all'assistente di leggere lo stato del sistema, verificare la configurazione attiva, analizzare i piani di volo (`oa-plan.json`) o controllare i log di esecuzione senza richiedere comandi manuali da parte dell'utente.
* **Esecuzione assistita:** Su esplicita richiesta e sotto il controllo dell'amministratore, l'agente può avviare operazioni di diagnostica o preparare i passaggi di remastering.

---

## 2. Gestione e Sicurezza del Modulo (`eggs mcp`)

L'integrazione è progettata ponendo la sicurezza al primo posto, gestendo i permessi di esecuzione tramite comandi dedicati:

* **Abilitazione:**
  ```bash
  sudo eggs mcp enable
  ```
   Configura il daemon MCP, predispone i collegamenti con i client IA supportati e imposta le regole di sicurezza granulari per l'esecuzione dei privilegi.
* **Verifica dello Stato:**
  ```bash
  eggs mcp status
  ```
  Restituisce un report immediato sull'attivazione del server, sulle connessioni attive e sulla corretta registrazione dei tool presso gli ambienti di sviluppo.
* **Disabilitazione e Pulizia:**
  ```bash
  sudo eggs mcp disable
  ```
  Rimuove la configurazione MCP dai client IA e purga i file di autorizzazione temporanei dal sistema.

Grazie a questa architettura, `penguins-eggs` diventa il primo sistema di remastering nativamente "AI-ready", capace di farsi coadiuvare da agenti intelligenti nella manutenzione, configurazione e clonazione dell'habitat.
